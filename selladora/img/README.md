# Fotos del producto — SealMate (selladora)

Coloca aquí las **4 fotos reales** de la selladora, con estos nombres exactos:

| Archivo | Qué foto poner |
|---|---|
| `producto-1.webp` | Foto principal (la selladora en uso sellando una bolsa) |
| `producto-2.webp` | Infografía de usos (chips, galletas, bolsas de congelar, comida de mascota) |
| `producto-3.webp` | Producto limpio sobre fondo blanco |
| `producto-4.webp` | Otra vista (tamaño/portátil, el modelo azul, etc.) |

> El código también acepta `.jpg` y `.png`.

## Cómo guardar la foto GRANDE (no la miniatura)

1. En AliExpress, **haz clic en la imagen grande** del producto para ampliarla.
2. Si el clic derecho no deja guardar, usa el **recorte de pantalla**: `Windows + Shift + S`,
   selecciona la imagen, y guarda el recorte como `producto-1.jpg` … `producto-4.jpg`.
3. Comprueba que el archivo pese **más de ~30 KB** (si pesa 1 KB, es la miniatura).

## Cómo subirlas a GitHub

1. Ve a `selladora/img/` **en la rama `claude/dropshipping-contigo-hp6cm0`**.
2. **Agregar archivo → Cargar archivos** → arrastra las 4 fotos → **Confirmar cambios**.

Si algún archivo falta, se muestra una ilustración de respaldo, así que la web nunca se ve rota.
